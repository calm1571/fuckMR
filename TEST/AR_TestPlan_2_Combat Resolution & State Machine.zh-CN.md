## 测试模块

### 2. 战斗结算与状态机
验证命中、伤害、护盾、死亡、胜负等核心战斗规则是否正确。

**包含内容**
- 命中检测
- 命中 / 未命中结算
- 单次命中伤害计算
- 多次命中累计伤害
- 护盾优先级
- HP 下限钳制
- 致命命中的结果切换
- 死亡后的状态锁定
- Host 权威胜负判定

## 模块：战斗结算与状态机

> 说明：  
> - 本模块主要用于 **EditMode / 逻辑层测试**。  
> - 重点验证当前版本中的命中判定、伤害结算、护盾阻挡、HP 钳制以及致命命中后的结果切换是否正确且可确定复现。  
> - 执行测试前请保持 `Actual Outcome` 和 `Status` 为空。  
> - `Status` 建议使用：`Not Run`、`Pass`、`Fail`、`Blocked`、`N/A`。  
> - 若某项依赖当前版本中尚未确认实现的功能，请先标记为 `Blocked`，并补充实现核查链接或说明。
>
> 量化通过标准：
> - 单次有效命中的伤害值必须与当前构建配置下的 `GetDamage()` 完全一致。
> - 多次有效命中必须严格按 `N * GetDamage()` 累计，直到 HP 归零；HP 不允许低于 `0`。
> - 护盾激活窗口内应 `100%` 阻挡来袭伤害；被挡住的命中对 HP 的改变量必须为 `0`。
> - 致命伤害生效后，同一局内后续命中尝试对 HP 的改变量必须为 `0`。
> - 比赛结果必须在致命命中结算后 `500 ms` 内收敛为唯一胜者，之后不得发生胜者翻转。

#### 功能：命中结算（只有通过 host 侧几何命中判定的射击才会造成伤害）

|Test|Inputs|Expected Outcome|Actual Outcome|Status|
|---|---|---|---|---|
|HR-01 直接命中目标头部位置|A 发射一发子弹，其路径在命中半径内穿过目标头部位置|目标 HP 恰好减少 `GetDamage()` 一次|||
|HR-02 超出命中半径时判定为未命中|A 发射一发子弹，其最近点距离始终大于命中半径|不会发生 HP 变化，也不会触发结果切换|||
|HR-03 超出最大距离的射击|A 发射方向有效，但目标位于 `shot.maxDistance` 之外|不会判定命中，也不会发生 HP 变化|||
|HR-04 位于射手身后的目标|目标位置位于射击生成点后方|不会判定命中，也不会发生 HP 变化|||
|HR-05 多次有效命中累计正确|在无护盾时连续应用多次有效命中|HP 按 `N * GetDamage()` 累计下降，直到归零；不会额外多扣|||

#### 功能：护盾阻挡（护盾激活窗口内会阻挡来袭射击）

|Test|Inputs|Expected Outcome|Actual Outcome|Status|
|---|---|---|---|---|
|SH-01 护盾激活时阻挡命中|目标护盾结束时间仍在未来，且本次射击原本会命中|本次射击被护盾阻挡；HP 保持不变|||
|SH-02 护盾过期后命中恢复生效|同一目标在护盾过期后再次被命中|护盾窗口结束后，伤害恢复正常结算|||
|SH-03 护盾激活受冷却限制|在 `shieldCooldownUntil` 到期前再次尝试开盾|第二次激活被拒绝；不会延长护盾时间|||
|SH-04 护盾持续期间不可重复激活|护盾仍在有效期内时再次触发护盾|重复激活被拒绝；护盾结束时间不会被提前刷新|||
|SH-05 无护盾时正常受伤|目标当前无激活护盾且受到有效命中|HP 恰好减少 `GetDamage()`|||

#### 功能：HP 边界与死亡后锁定（HP 不会为负，死亡目标不再继续受伤）

|Test|Inputs|Expected Outcome|Actual Outcome|Status|
|---|---|---|---|---|
|HP-01 过量伤害不会使 HP 变负|目标 HP=10，并受到高于剩余 HP 的致命伤害|HP 变为 0，不会出现负数|||
|HP-02 死亡后再次受击被忽略|目标 HP 已为 0，再次收到有效射击|不会继续扣减 HP|||
|HP-03 连续受击时 HP 递减精确|重复施加非致命命中，直到接近 0|HP 每次按预期数值递减，不会出现 off-by-one|||
|HP-04 致命命中只触发一次结果切换|目标被一次致命命中打到 0|结果切换仅发生一次；后续被忽略的命中不会再次触发|||

#### 功能：结果切换（由 host 权威地在致命命中后结束比赛并确定唯一胜者）

|Test|Inputs|Expected Outcome|Actual Outcome|Status|
|---|---|---|---|---|
|WR-01 Host 击杀 Client|Client HP 因一次 host 侧有效命中降到 0|Host 进入结果界面并发送 `winnerRole = Host`|||
|WR-02 Client 击杀 Host|Host HP 因一次客户端射击被 host 结算后降到 0|Host 以 `winnerRole = Client` 结束比赛，双方分别显示胜负|||
|WR-03 非致命命中不会结束比赛|一次有效命中后目标 HP 仍大于 0|只更新 HP，不切换到 Result 状态|||
|WR-04 远端结果载荷能正确映射本地 WIN / LOSE|接收到 `winnerRole = Host` 或 `Client` 的 `MatchResultPayload`|各端都能正确映射为本地 `WIN` 或 `LOSE`|||
|WR-05 新一局重置后战斗状态恢复初始值|在一局结束后触发 rematch reset|HP、护盾计时、射击冷却门限和结果文本都恢复到初始状态|||
