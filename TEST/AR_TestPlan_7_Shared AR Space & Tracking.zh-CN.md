### 7. 共享 AR 空间与追踪
验证当前已连接的 Host / Client 设备，以及未来的 spectator 端，是否在同一物理环境中共享同一个 AR 空间。

**包含内容**
- 初始空间对齐
- 已连接设备共享同一虚拟原点
- 玩家相对位置一致
- 观战端看到正确的玩家落位
- 虚拟对象不漂移
- 长时间会话中空间保持稳定
- 追踪丢失与恢复
- 快速运动 / 快速转头时的稳定性
- 光照条件影响
- 遮挡影响
- 重定位后空间是否仍保持对齐

---

## 模块：共享 AR 空间与追踪

> 说明：  
> - 本模块主要用于 **PlayMode / 同地 Host-Client 集成测试**。  
> - 重点验证 Host 与 Client 是否在同一真实环境中共享同一虚拟空间，并保持稳定的相对位置关系与追踪状态。  
> - 建议记录日志：shared anchor uuid（若启用）、worldRoot 的位置 / 旋转、room / match 标识、pose（position / rotation）以及关键恢复告警日志。  
> - spectator 相关条目在本计划中会被刻意保留，作为即将接入第三端角色后的前瞻性覆盖，即使当前构建主要仍是 Host / Client 双端。  
> - 执行测试前请保持 `Actual Outcome` 和 `Status` 为空。  
> - `Status` 建议使用：`Not Run`、`Pass`、`Fail`、`Blocked`、`N/A`。  
> - 若某项依赖当前版本中尚未确认实现的功能，请先标记为 `Blocked`，并补充实现核查链接或说明。
>
> 量化通过标准：
> - 初始共享空间对齐目标：校准完成后，等价参考点误差 <= `15 cm`，yaw 误差 <= `10 deg`。
> - 玩家相对落位目标：正常站立 / 移动检查下，远端玩家位置误差 <= `20 cm`。
> - 静止共享物体漂移目标：`30 s` 内 <= `10 cm`；长时间运行漂移目标：`10 min` 内 <= `20 cm`。
> - Tracking Lost / relocalization 恢复通过标准：受影响设备在恢复后 `2 s` 内回到 <= `20 cm` 的位置误差。
> - 快速运动时允许瞬时误差上升，但必须在 `2 s` 内回落到 <= `30 cm`；spectator 条目在第三端可用后沿用同一阈值。
