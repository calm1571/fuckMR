### 7. 多角色空间对齐与追踪稳定性
验证当前版本中 Host / Client / Spectator 通过五步串行校准建立的本地视觉对齐，是否足够稳定、可恢复且不破坏战斗逻辑。

**包含内容**
- 初始五步校准流程正确
- Host / Client / Spectator 的本地视觉对齐正确
- 玩家相对位置一致性
- Spectator 看到正确的玩家落位
- 虚拟对象不明显漂移
- 长时间会话中对齐保持稳定
- 追踪丢失与恢复
- 快速运动 / 快速转头时的稳定性
- 光照条件影响
- 遮挡影响
- 重定位后对齐是否仍保持可用

---

## 模块：多角色空间对齐与追踪稳定性

> 说明：  
> - 本模块主要用于 **PlayMode / 同地三端集成测试**。  
> - 当前版本主线并非完整共享空间锚模型，而是基于五步串行校准与多端本地视觉对齐。测试目标应围绕“当前实现是否稳定可用”，而不是验证绝对共享原点。  
> - 建议记录日志：calibrationPhase、worldRoot 位置 / 旋转、远端代理对齐偏移、tracking 状态、relocalization 告警日志。  
> - 执行测试前请保持 `Actual Outcome` 和 `Status` 为空。  
> - `Status` 建议使用：`Not Run`、`Pass`、`Fail`、`Blocked`、`N/A`。  
> - 若某项依赖当前版本中尚未确认实现的功能，请先标记为 `Blocked`，并补充实现核查链接或说明。
>
> 量化通过标准：
> - 初始对齐目标：五步校准完成后，各端对自己关注对象的等价参考点误差 <= `25 cm`，yaw 误差 <= `15 deg`。
> - 玩家相对落位目标：正常站立 / 移动检查下，远端玩家位置误差 <= `30 cm`。
> - 静止观察漂移目标：`30 s` 内 <= `15 cm`；长时间运行漂移目标：`10 min` 内 <= `25 cm`。
> - Tracking Lost / relocalization 恢复通过标准：受影响设备在恢复后 `2 s` 内回到 <= `30 cm` 的位置误差。
> - 快速运动时允许瞬时误差上升，但必须在 `2 s` 内回落到 <= `40 cm`；不允许出现持续错误锚定导致战斗关系失真。
